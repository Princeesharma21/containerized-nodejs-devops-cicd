 Containerized Node.js DevOps CI/CD Pipeline

 Project Overview

This project demonstrates the implementation of a DevOps CI/CD workflow for a Node.js application. It integrates containerization, automated continuous integration, pipeline automation, reverse proxy configuration, and Kubernetes deployment manifests to illustrate modern DevOps practices.

 Technologies Used

 Node.js & Express.js — Application development
 Docker & Docker Compose — Containerization
 GitHub Actions — Continuous integration
 Jenkins — CI/CD pipeline automation
 Nginx — Reverse proxy
 Kubernetes — Container orchestration and deployment
 Git & GitHub — Version control

 Key Features

 Containerized Node.js application using Docker.
 Automated CI workflow with GitHub Actions.* Jenkins pipeline configuration for CI/CD automation.
 Multi-service configuration using Docker Compose.
 Nginx reverse proxy configuration.
 Kubernetes manifests for deployment, service discovery, and ingress.
 Shell scripts for build and deployment tasks.
